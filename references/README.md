# Références

Un dossier par motion analysé. Chaque dossier contient :

- les sorties de `tools/decortique.py` (planches, transitions, palette, audio) ;
- une fiche `analyse.md` rédigée à partir du modèle ci-dessous.

## M'envoyer une référence

| Moyen | Quand l'utiliser |
|---|---|
| Fichier vidéo déposé dans `references/a-analyser/` sur GitHub | vidéos de moins de 25 Mo (limite de l'upload web GitHub) |
| Lien Google Drive | vidéos lourdes ; le connecteur Drive est déjà branché |
| Captures d'écran ou GIF directement dans le chat | pour montrer un détail précis |
| Lien YouTube, Instagram, Vimeo, TikTok | seulement si ces sites sont autorisés dans le réseau de l'environnement cloud |

## Modèle de fiche `analyse.md`

```markdown
# <Nom du motion>

Source : <lien ou fichier> · Auteur/studio : <si connu>
Format : <ratio, durée, fps> · Plans : <nombre, durée moyenne>

## Ce qui le rend stylé
<2 ou 3 phrases : l'idée visuelle forte>

## Décomposition
| Temps | Ce qu'on voit | Technique | Outil probable |
|---|---|---|---|

## Transitions
<chaque type de transition, comment elle est construite>

## Typo
<polices (ou équivalents gratuits), animation des lettres, mise en page>

## Couleurs
<palette, rôle de chaque couleur>

## Rythme et son
<tempo, synchronisation image/son, sound design>

## Ce qu'on récupère pour la machine
- [ ] <technique> → <outil> 
```
